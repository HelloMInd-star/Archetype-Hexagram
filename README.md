## 🧠 什么是 Archetype Hexagram？

**Archetype Hexagram** 是一个交互式人格原型系列，将 **MBTI 人格类型**、**阴阳八卦** 与 **动物原型** 融合为可交互的视觉实验。

每一个“原型”都是一只动物，对应一种人格气质组：
- **坤牛 ☷** — SJ · 阵地守将 · 厚德载物
- 更多原型陆续加入：乾龙（NT）、离凤（NF）、坎龟（SP）……

> 把人格穿在动物身上，用交互验证直觉。


## 🐂 Vol.1：坤牛 · 厚德射覆

点击坤牛头像，进入第一个交互原型：

- **蓄力**：按住左键，三阴爻逐一点亮，粒子向内收敛
- **发射**：松开发射，指数蓄力转化为金色能量弹
- **靶心**：红色乾阳靶标，命中即“射覆”

机制对应“坤为三阴，能量向内收敛，蓄力越久释放越强”，数学模型为 `y = A · r^t`。
